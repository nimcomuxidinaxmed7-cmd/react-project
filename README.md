ShopEase – E-commerce Website

About the Project

ShopEase is a simple e-commerce website built using React. The idea behind this project was to create an online shopping experience where users can browse products, view product details, add items to their cart, and manage their shopping easily.

I wanted to build something practical that represents how a real online shopping website works while improving my understanding of React and frontend development.

 Features

- Product Listing: Users can browse different products available on the website.
- Product Details: Users can view more information about individual products.
- Shopping Cart:Users can add products to their cart and manage their selected items.
-API Integration: Product information is fetched from an external API.
- React Components: The website is divided into reusable components to keep the code organised.
- Responsive Design:The website is designed to work on different screen sizes, including mobile phones, tablets, and desktops.
- Routing: Users can navigate between different pages of the website.

Technologies Used

- React – For building the user interface.
- JavaScript – For the website's functionality.
- Tailwind CSS – For styling and responsive design.
- HTML – For structuring the content.
- React Router – For navigating between pages.
- Vitest and React Testing Library – For testing components and checking that they work as expected.
- Git and GitHub – For version control and project management.

Getting Started

To run this project on your local machine:

1. Clone the repository:


   git clone YOUR_GITHUB_REPOSITORY_LINK

2. Open the project folder:

   cd shopease


3. Install the dependencies:


   npm install


4. Start the development server:

   npm run dev
   

5. Open the local URL provided in your terminal.

Running Tests

To run the project tests, use:

npm run test
